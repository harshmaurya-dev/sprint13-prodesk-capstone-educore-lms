# EduCore LMS — Prodesk Sprint 13 Capstone

Enterprise Learning Management System built with React, Vite, Node.js, Express, MongoDB and JWT.

## Features
- Authentication
- Role-based users
- Course catalog
- Enrollment
- Student dashboard
- Progress tracking

## Core Views
1. Auth Screen
2. Dashboard
3. Course Details

## Architecture
React Client → Express API → MongoDB
